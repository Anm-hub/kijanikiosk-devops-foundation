# Week 8 Pull Request Summary

This project delivers a container-based deployment pipeline for KijaniKiosk Payments. It includes a multi-stage production image, version-and-commit-based image tagging, publishing and retrieval through GitHub Container Registry, and Kubernetes Deployment and NodePort Service manifests. The production image was reduced from a 274 MB baseline to 82 MB, runs as a non-root user, and passed its health verification. The Kubernetes deployment successfully ran two replicas, exposed the application through a Service, and demonstrated Pod self-healing after a Pod was deleted. A confident design decision was using a multi-stage production image because it separates build tooling from the runtime image, reducing image size and unnecessary production dependencies. With one additional day, I would improve the deployment with readiness and liveness probes, externalised configuration, and more detailed recovery-time monitoring.
